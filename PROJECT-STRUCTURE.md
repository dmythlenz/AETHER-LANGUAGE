# AETHER-LANGUAGE canonical repository structure

The repository is organized by responsibility, not by historical artifact names.

- language/: language semantics, universal source, canonical manifest
- compiler/: compiler contracts, FFI, optimizer
- runtime/: execution, concurrency, compatibility runtimes
- std/: standard library
- ai/: AI/LLM/agent layers
- game/: ECS/graphics/game systems
- os/: OS/kernel contracts
- web/: server/full-stack layer
- targets/: backend/ABI boundaries by platform
- tooling/: CLI, package manager, debugger, formatter, LSP
- tests/: conformance and verification
- docs/: specification, tutorials, API and engineering docs
- examples/: runnable examples
- apps/: browser/workbench/runtime applications
- compat/: migration and backwards-compatibility assets
